## 🌌 The Celestial Experience Aura

When a player attains **Level 30** or above, they unlock a swirling celestial particle vortex that ascends around their character model.

```
                  *  .  +  (Gold Sparkle)
                 .  *  +  .
             +      ( O )      +  y = 2.2m (Apex)
              *    /  |  \    *
                + [ Player ] +    y = 1.0m (Midpoint)
                 *   / \   *
               +    *   +    +    y = 0.0m (Feet)
        ───────────────────────────────
```

### 1. Dual-Layer Toggle System
To ensure maximum visual accessibility and low-end client performance, the aura operates under a strict two-tier authority system:
1. **Server Authority (`levelPowerEnableAura`)**:
   - If `false`, the server syncs `DATA_AURA_LEVEL = 0` to all tracking clients. No client spawns particles.
2. **Client Autonomy (`enableClientAuraParticles`)**:
   - If an individual player experiences FPS drops, they can set `enableClientAuraParticles = false` locally via the YACL config screen. The client immediately stops rendering particles for all surrounding players.

## 🎵 Auditory Pitch Modulation & Ascension Chimes

### 1. Dynamic Experience Orb Pitch Scaling
In vanilla Minecraft, picking up experience orbs plays `entity.experience_orb.pickup` at a randomized pitch between $0.55$ and $1.25$.  
`ClientPacketListenerMixin` intercepts this sound and adds a level-based shift:
$$\Delta p = 0.015 	imes 	ext{level}$$
$$p_{	ext{final}} = \min(p_{	ext{vanilla}} + \Delta p, 2.0)$$

| Experience Level | Pitch Shift ($\Delta p$) | Resulting Sound Character |
| :--- | :--- | :--- |
| **Level 0** | $+0.000$ | Standard vanilla chimes |
| **Level 10** | $+0.150$ | Noticeably brighter pickup tone |
| **Level 30** | $+0.450$ | Resonant crystal chime |
| **Level 60** | $+0.900$ | High-frequency celestial ping |
| **Level 100+** | $+1.500$ (clamped at 2.0) | Pure brilliant harmonic apex |

### 2. Milestone Ascension Chimes
Upon reaching major milestone levels, the server broadcasts `SoundEvents.UI_TOAST_CHALLENGE_COMPLETE` at volume `0.8f` and pitch `1.2f`:
* **Level 30**: Unlocking the Celestial Aura.
* **Level 60**: Veteran Ascendant milestone.
* **Level 100**: Century Master Paragon milestone.
