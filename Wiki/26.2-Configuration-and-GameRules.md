## ⚙️ Server GameRules Reference Matrix

All server mechanics are governed by Dynamic GameRules registered via `DasikLibrary`. Administrators can adjust these values in real-time without restarting the server:

| GameRule Name | Type | Valid Range | Default | Translation Description |
| :--- | :--- | :--- | :--- | :--- |
| `leveldoessomething:levelPowerCurveType` | `Integer` | `0 .. 2` | `1` | The mathematical curve used to calculate attribute scaling. 0 = Exponential Tier steps, 1 = Smooth Logarithmic curve, 2 = Simple Linear scaling. |
| `leveldoessomething:levelPowerBaseMultiplier` | `Integer` | `0 .. 1000` | `10` | The base multiplier applied per level in basis points (1/10000). A value of 10 represents 0.001 (0.1% increase). |
| `leveldoessomething:levelPowerMaxTier` | `Integer` | `1 .. 30` | `10` | The maximum tier multiplier allowed when using the exponential tier system. |
| `leveldoessomething:levelPowerEnableAura` | `Boolean` | `true / false` | `true` | When true, players at or above level 30 will spawn ambient experience-themed particles visible to all surrounding players. |
| `leveldoessomething:levelPowerEnableSoundPitch` | `Boolean` | `true / false` | `true` | When true, experience collection sounds will be pitch-shifted higher as the player's level increases, providing auditory feedback. |

### In-Game Command Examples
```mcfunction
# Query current curve type
/gamerule leveldoessomething:levelPowerCurveType

# Switch to Linear progression curve
/gamerule leveldoessomething:levelPowerCurveType 2

# Double all attribute scaling bonuses (20 basis points = 0.2% per unit)
/gamerule leveldoessomething:levelPowerBaseMultiplier 20

# Disable particle auras globally on the server
/gamerule leveldoessomething:levelPowerEnableAura false
```

## 💻 Client Configuration Schema (`level-does-something-client.json`)

Located at `.minecraft/config/level-does-something-client.json`:

```json
{
  "enableClientAuraParticles": true,
  "enableClientSoundPitch": true
}
```

### Safety & Atomic Replacement Architecture
1. **Atomic Write Pipeline**: Changes written via GUI or code write to `level-does-something-client.json.tmp` and execute an atomic file move (`StandardCopyOption.ATOMIC_MOVE`).
2. **50 KB Safety Guard**: If a corrupted file exceeds 50 KB, the engine resets to safe defaults.
3. **Automatic Backup Restoration**: If parsing errors occur, the mod automatically restores configuration from `level-does-something-client.json.bak`.
